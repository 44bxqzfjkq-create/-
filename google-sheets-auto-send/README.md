# 依頼リスト 自動送信（Google スプレッドシート）

スプレッドシートの1行＝1件の依頼として管理し、**「送信」列のチェックを入れると
その行の内容を Discord / Slack へ送信し、成功したら行を自動で削除**します。
削除された分だけ下の依頼が繰り上がるので、上から順に「送信 → 依頼完了 → 次へ」を
回していけます。

## このスクリプトの特徴

- **列の「見出し名」で項目を探す**ので、列の並び順が違っても、他の列が混ざっていても
  そのまま動きます。
- **既存の見出しやデータは壊しません。** 足りない「送信」列だけ右端に追加します。

## 送る項目

`CONFIG.FIELDS` に並べた見出しの内容を送ります（初期値）：

```
受付番号 / 希望メニュー / 金額 / 連絡先 / 備考 / 写真
```

- 見出し名は、あなたのシートの見出しと **完全に一致** させてください（全角/半角・スペースに注意）。
- **写真** は画像URL（Google Drive の共有リンクや画像URL）のテキストが入っている前提です。

## セットアップ手順

### 1. Discord の Webhook URL を用意する

Webhook URL は**サーバー内の特定チャンネル**に紐づきます（そのチャンネルへ届きます）。

1. Discord でサーバーを開く
2. 送り先チャンネルの歯車（**チャンネルの編集**）
3. 「**連携サービス（Integrations）**」→「**ウェブフック**」→「**新しいウェブフック**」
4. 名前・アイコンは任意 →「**ウェブフックURLをコピー**」

URL はこの形です：`https://discord.com/api/webhooks/xxxxx/yyyyy`

> Slack を使う場合は Incoming Webhook の URL を用意し、`WEBHOOK_TYPE` を `'slack'` に。

### 2. スクリプトを貼り付けて設定する

1. スプレッドシートを開く
2. メニュー「**拡張機能 > Apps Script**」を開く
3. 既存コードを消して `Code.gs` の中身をすべて貼り付ける
4. `CONFIG` を編集：
   ```js
   WEBHOOK_URL: 'コピーしたWebhook URL',
   WEBHOOK_TYPE: 'discord',      // Slack なら 'slack'
   SHEET_NAME: 'あなたのシート名', // タブ名に合わせる（例: 'シート1'）
   // 見出し名がシートと違う場合は FIELDS / MONEY_HEADER / SEND_HEADER も調整
   ```
5. 保存

### 3. 初期設定を実行する

1. スプレッドシートに戻って画面を再読み込み
2. 「**依頼管理 > 初期設定（送信列＋自動送信ON）**」をクリック
3. 初回は権限確認が出るので許可する
4. 右端に「送信」列（チェックボックス）が追加されればOK

> `FIELDS` の見出しがシートに見つからない場合は、その名前を知らせるメッセージが出ます。
> 見出し名を一致させてから、もう一度「初期設定」を実行してください。

### 4. 動作確認

- 「**依頼管理 > 送信テスト**」で Discord / Slack に届くか確認できます。
- データ行の **「送信」列にチェック**を入れると、その行が送信され、自動で削除されます。

## 使い方（毎回）

1. 依頼を上から入力していく
2. 対応が済んだ依頼の **「送信」列にチェック** を入れる
3. Webhook に送信され、その行は自動で消える → 下の依頼が繰り上がる

> 送信に**失敗**した場合は、行は消えずにチェックが外れます（消えないので安全）。
> `WEBHOOK_URL` / `WEBHOOK_TYPE` の設定を見直してください。

## よくある調整

- **送る項目・順番を変えたい**：`CONFIG.FIELDS` の見出し名を並べ替え・追加・削除。
- **金額の見出しが違う**：`CONFIG.MONEY_HEADER` を実際の見出し名に。
- **送信列の名前を変えたい**：`CONFIG.SEND_HEADER` を変更。
- **見出しが1行目じゃない**：`CONFIG.HEADER_ROW` を変更。
- **チェックではなくメニューから送りたい**：行を選択して「依頼管理 > 選択した行を今すぐ送信」。

