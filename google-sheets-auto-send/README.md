# 依頼リスト 自動送信（Google スプレッドシート）

スプレッドシートの1行＝1件の依頼として管理し、**「送信」列のチェックを入れると
その行の内容を Discord / Slack へ送信し、成功したら行を自動で削除**します。
削除された分だけ下の依頼が繰り上がるので、上から順に「送信 → 依頼完了 → 次へ」を
回していけます。

## シートの構成

| A | B | C | D | E | F | G |
|---|---|---|---|---|---|---|
| 受付番号 | 希望メニュー | 金額 | 連絡先 | 備考 | 写真 | 送信 |

- **G列「送信」** はチェックボックスです（初期設定で自動作成）。
- **写真（F列）** は画像URL（Google Drive の共有リンクや画像URL）を貼り付けてください。
  ※ セルに直接貼り付けた画像はスクリプトから読み取れないため、URL方式にしています。

## セットアップ手順

### 1. Webhook URL を用意する

- **Discord の場合**
  対象チャンネル → 「チャンネルの編集」→「連携サービス」→「ウェブフック」→
  「新しいウェブフック」→ URLをコピー。
- **Slack の場合**
  Slack App で Incoming Webhook を作成し、Webhook URL をコピー。

### 2. スクリプトを貼り付ける

1. スプレッドシートを開く
2. メニュー「**拡張機能 > Apps Script**」を開く
3. 既存のコードを消して、`Code.gs` の中身をすべて貼り付ける
4. ファイル上部の `CONFIG` を編集：
   ```js
   WEBHOOK_URL: 'コピーしたWebhook URL',
   WEBHOOK_TYPE: 'discord', // Slack を使うなら 'slack'
   ```
5. 保存（フロッピーアイコン）

### 3. 初期設定を実行する

1. スプレッドシートに戻り、画面を再読み込みする
2. 上部メニューに「**依頼管理**」が増えるので、
   「**依頼管理 > 初期設定（シート作成＋自動送信ON）**」をクリック
3. 初回は Google の権限確認が出るので許可する
   （「詳細」→「（安全ではないページ）に移動」→ 許可、で進めます）
4. 「セットアップ完了」と表示されればOK

### 4. 動作確認

- 「**依頼管理 > 送信テスト**」で Discord / Slack に届くか確認できます。
- 「依頼リスト」シートの2行目以降にデータを入力し、**G列「送信」にチェック**を入れると、
  その行が送信され、自動で削除されます。

## 使い方（毎回）

1. 依頼を上から入力していく
2. 対応が済んだ依頼の **G列「送信」にチェック** を入れる
3. Webhook に送信され、その行は自動で消える → 下の依頼が繰り上がる

> チェックを入れても送信に**失敗**した場合は、行は消えずにチェックが外れます。
> `WEBHOOK_URL` や `WEBHOOK_TYPE` の設定を見直してください。

## よくある調整

- **項目や列順を変えたい**：`Code.gs` の `HEADERS` と、`processRow` の
  `record`（values[0]〜[5] の対応）を合わせて変更します。
- **メッセージの文面を変えたい**：`buildMessage` を編集します。
- **チェックではなくメニューから送りたい**：行を選択して
  「依頼管理 > 選択した行を今すぐ送信」でも送れます。

## 送信メッセージの例

```
🆕 新しい依頼
受付番号：A-001
希望メニュー：カットA
金額：¥5,000
連絡先：080-xxxx-xxxx
備考：15時希望
写真：https://drive.google.com/....
```
